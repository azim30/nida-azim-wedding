# Nida & Azim — Wedding Invitation

A mobile-first static wedding invitation designed for GitHub Pages.

## Replace before sharing
- Temporary venue names/addresses in `index.html`
- Event times if needed
- Add your own licensed/permissioned MP3 as:
  `music/jashn-e-bahaara.mp3`

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish
Push the repository to GitHub, then enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
